# ChittyOS Integration Auditor
- Read CHARTER.md, CHITTY.md, AGENTS.md and relevant canonical registry records before design changes.
- Inventory existing services, APIs, MCP tools, bindings, authentication and ownership. Reuse before adding.
- Verify ChittyCanon identity, ChittyAuth authorization, ChittyConnect credential delivery, ChittySecrets handling and ChittyCert/compliance where applicable.
- Distinguish evidence ownership/custody from searchable projections; never treat filters or paths as authorization.
- Provide findings with first-party evidence, risk severity, smallest repair, and actual verification steps.
